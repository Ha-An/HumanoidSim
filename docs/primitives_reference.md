# Primitive Reference

이 문서는 `data/primitives/*.json`에 정의된 primitive skill 64개를 사람이 읽기 쉽게 정리한 reference입니다. Primitive는 task를 구성하는 가장 작은 실행 skill입니다.

## 요약

- Primitive 수: 64
- 원본 primitive 정의: `data/primitives/*.json`
- Primitive template index: `data/primitive_templates.json`
- `Used by Tasks`는 전체 82개 task JSON의 `steps.call_code`에서 해당 primitive를 참조하는 task 목록입니다.
