# Task Reference

이 문서는 `data/tasks/*.json`에 정의된 HumanoidSim core task 82개를 사람이 읽기 쉽게 정리한 reference입니다. 각 task의 실제 실행 정의는 JSON 파일이 원본이며, 이 문서는 탐색과 검토를 위한 요약입니다.

### Task Level 판정 기준

`Atomic Task`와 `Composite Task`는 primitive sequence의 길이만으로 구분하지 않습니다. 기준은 task가 표현하는 작업 의미의 범위와 실행 중 workflow 성격입니다.

| Level | 판정 기준 | 대표 신호 |
| --- | --- | --- |
| `ATOMIC_TASK` | 하나의 명확한 목표를 가진 단일 작업 단위입니다. | 입력과 결과가 비교적 직접적이고, 실행 흐름이 큰 정책 분기 없이 primitive sequence로 닫힙니다. |
| `COMPOSITE_TASK` | 여러 작업, 절차, 정책 판단, 시스템 update, 에스컬레이션을 묶은 운영 workflow입니다. | 조건에 따라 세부 절차가 달라지거나, 여러 resource/location/system을 조합하거나, 하위 atomic task로 분해할 수 있습니다. |

예를 들어 `RECOVER_FROM_FAULT`는 현재 primitive sequence가 짧지만, `fault_code`와 `policy`에 따라 자동 복구, 실패 처리, assistance 요청, 안전 절차가 달라질 수 있으므로 `COMPOSITE_TASK`로 분류합니다. 반대로 `TRANSFER`처럼 여러 primitive를 포함하더라도 목표가 좁고 실행 의미가 단일하면 `ATOMIC_TASK`로 분류합니다.
